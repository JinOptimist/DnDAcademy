Добавь противника в `Enemies/` по ссылке.

Аргумент пользователя: $ARGUMENTS

1. Прочитай skill: `.cursor/skills/add-enemy/SKILL.md`
2. Эталон формата: `Enemies/Mimic.md`
3. Скачай страницу по URL. Если URL нет — спроси Повелителя.
4. Создай (или замени) `Enemies/<Имя>.md` по шаблону skill.
