# Противник из бестиария → Enemies/

## Когда

Пользователь даёт URL карточки монстра (обычно `next.dnd.su/bestiary/…`).

## Файл

- Папка: `Enemies/`
- Имя: английское имя со страницы, латиницей, без пробелов (`Mimic.md`). Нет английского — транслит.
- Существующий файл с тем же именем — заменить.

## Как собрать

1. Скачай страницу (WebFetch / аналог).
2. Бери только игровые данные: размер/тип/мировоззрение, КЗ, инициатива, хиты, скорость, характеристики, навыки, иммунитеты, чувства, языки, среда, сокровища, опасность, особенности, действия, бонусные/реакции/легендарные (если есть).
3. Убери «?» глоссария сайта.
4. Не копируй комментарии, галерею, меню сайта.
5. Длинный лор сожми в 1 строку в «За стол». Таблицы обликов/тактики — коротко, если нужны за столом.
6. В конце: `Источник: [dnd.su, имя](url).`

Документ короткий. Обращение в ответе: Повелитель. В ответе — путь к файлу.

## Особенности

**Имя.** Текст.

## Действия

**Имя.** Текст.

## Бонусные действия

Только если есть на странице.

Одна строка сути. Дальше — только то, что нужно в бою/сцене.

Источник: [dnd.su, имя](url).
