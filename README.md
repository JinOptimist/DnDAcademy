# DnD Academy

Привет, **Повелитель**.

Материалы партии в Стриксхейвене: письма, сессии, карточки за стол, канон книги.

## Документы

Короткие. Только то, что нужно за столом или для подготовки. Списки лучше абзацев.

Зачитка (блок «зачитать») — что герои видят и слышат. Как это устроено — в заметках мастера.

## Структура

- `InitationLeters/` — шаблоны письма о зачислении (`Приглашение-М.md`, `Приглашение-Ж.md`). Как заполнять — там же в README.
- `Session0/` — подготовительные курсы до писем о зачислении: `План.md`. Игроки приходят 0 уровнем, уходят 1-м.
- `Session1/` — план первой сессии (глава 3 канона, «Переполох в кампусе»): `План.md`.
- `ForPrint/` — карточки для печати: NPC, локации, предметы, зацепки сессии. Ключ `0001`… в имени файла и в первой строке документа. PDF: `/print` (или `python scripts/md-to-pdf.py <путь или ключ>`) → `ForPrint/ReadyForPrint/`.
- `InspiredOf/` — канон *Стриксхейвен: Учебная программа хаоса*. Оглавление: `core.md`.
