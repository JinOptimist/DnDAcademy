# Пригласительные письма

Шаблоны письма о зачислении в Стриксхейвен. Два варианта: `Приглашение-М.md`, `Приглашение-Ж.md`.

## Как персонализировать

- `{ИМЯ}` — имя персонажа (в письме встречается дважды).
- `{РАСА + ПРЕДЫСТОРИЯ}` — единственный абзац, который меняется под игрока. 2–3 фразы.

Идеи для абзаца по предысториям:

| Предыстория | Крючок |
| --- | --- |
| Лорхолд | Прочитал весь список рекомендованной литературы; поручился археомант с раскопок |
| Призмари | Прислал работу, которая до сих пор шумит в приёмной |
| Квандрикс | Решил задачу, которую комиссия считала нерешаемой |
| Сильверквилл | Письмо-прошение зачитывали вслух как образец |
| Визерблум | Вырастил то, что не должно было расти |

По расе — одна деталь: жильё и быт (крылья совлина, рост локсодона), язык, слухи о земляках в кампусе.

## Правила

- Не более 5 коротких абзацев — письмо должно влезать на пол-листа A4.
- Личное — только в одном абзаце, остальное общее для всех.
