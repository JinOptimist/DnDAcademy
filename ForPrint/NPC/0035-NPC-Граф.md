# 0035 NPC Граф

**Дворецкий-конструкт поместья капитана Пятнистокрыла.**

Портрет: стр. 217 оригинала (проводник по кампусу).

- Носит серебряный жилет, чёрный фрак и галстук.
- Ночью ходит по Большому залу (C3).
- Без профессоров принимает героев за грабителей.
- Перед нападением объявляет: «Граф приказывает вам уйти!»
- Использует параметры проводника по кампусу Стриксхейвена.
